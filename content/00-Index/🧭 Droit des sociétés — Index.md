## Conceptual Framework

### Company Lifecycle
```
CREATION
    │
    ├─→ Formation (statuts, apports)
    ├─→ Immatriculation (RCS)
    └─→ Acquisition personnalité morale
            │
OPERATION ──┤
            ├─→ Gouvernance (dirigeants, assemblées)
            ├─→ Droits des associés
            └─→ Contrôle (commissaires)
            │
EVOLUTION ──┤
            ├─→ Modifications statutaires
            ├─→ Opérations sur capital
            ├─→ Restructurations (fusion, scission)
            └─→ Groupes de sociétés
            │
TERMINATION ┤
            ├─→ Dissolution (causes)
            └─→ Liquidation
```

### Liability Architecture
```
UNLIMITED LIABILITY          LIMITED LIABILITY
├─ Société civile            ├─ SARL / SARL-S
├─ SNC                       ├─ SA
└─ Associés commandités      ├─ SAS
   (SCS, SCA)                ├─ SE
                             └─ Associés commanditaires
                                (SCS, SCA)
```
