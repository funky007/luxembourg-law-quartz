## 🏗️ Conceptual Cross-References

### Liability Architecture
```
Contractual (art. 1147)     Extra-contractual (arts. 1382-1384)
        │                              │
        └──── NON-CUMUL ───────────────┘
              (cannot combine)
```

### Nullity Framework
```
NULLITÉ ABSOLUE                    NULLITÉ RELATIVE
├─ Ordre public violation          ├─ Vices du consentement
├─ Objet illicite/impossible       ├─ Incapacité
├─ Cause illicite                  ├─ Lésion (art. 1118)
├─ 30 years                        ├─ 5 years (1 year for lésion)
├─ Any interested party            ├─ Protected party only
├─ Ex officio by judge             ├─ Must be invoked
└─ No confirmation                 └─ Confirmable
```

### Remedies Hierarchy
```
INEXÉCUTION
    │
    ├─→ Exception d'inexécution (defensive)
    │
    ├─→ Exécution forcée
    │       ├─ En nature
    │       └─ Par équivalent (D&I)
    │
    └─→ Résolution
            ├─ Judiciaire (art. 1184)
            ├─ Unilatérale (urgence)
            └─ Conventionnelle (clause résolutoire)
```

## 📋 Banking & Finance Focus Areas

For Luxembourg banking practice, prioritize:

1. **[[Capacité (arts. 1123-1125)]]** — corporate capacity, ultra vires
2. **[[Cause (arts. 1131-1133)]]** — upstream guarantees, corporate benefit
3. **[[Dol (art. 1116)]]** — réticence dolosive, disclosure duties
4. **[[Solidarité (art. 1202)]]** — joint and several liability
5. **[[Prescription extinctive]]** — limitation periods for claims
6. **[[Non-cumul des responsabilités]]** — contractual vs delictual
