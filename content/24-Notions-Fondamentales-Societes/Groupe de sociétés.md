# Groupe de sociétés

> **Type**: Notion Fondamentale
> **Source**: Steichen, *Précis de droit des sociétés*, Titre 4, Ch. 3
> **Key Legislation**: Various L1915 provisions; EU Accounting Directive

---

## Definition

**Steichen**: A *groupe de sociétés* (corporate group) is an economic ensemble of legally distinct companies linked by capital participation or control, with a parent company (*société mère*) exercising direction over subsidiaries (*filiales*).

---

## Key Principle

**Steichen**: Each company in a group:
- Has separate legal personality
- Is a distinct legal person
- Has own patrimony
- Parent not automatically liable for subsidiaries

---

## Types of Relationships

| Relationship | Description |
|--------------|-------------|
| **Filiale** | Company controlled by parent (>50% voting) |
| **Participation** | Significant stake (usually >20%) |
| **Société mère** | Company holding control |
| **Holding** | Company whose main activity is holding stakes |

---

## Control Criteria

**Steichen**: Control exists when:

| Criterion | Description |
|-----------|-------------|
| **Majority voting** | >50% voting rights |
| **Board control** | Power to appoint majority of board |
| **Contract** | Control by agreement |
| **De facto** | Actual exercise of dominant influence |

---

## Group Consequences

### Consolidated Accounts

| Requirement | Description |
|-------------|-------------|
| **Consolidation** | Parent must consolidate controlled entities |
| **Exemptions** | Small groups, sub-holdings |
| **Standards** | Luxembourg GAAP or IFRS |

### Intragroup Transactions

| Aspect | Rule |
|--------|------|
| **Arm's length** | Must be at market terms |
| **Transfer pricing** | Tax rules apply |
| **Corporate benefit** | Each company must benefit |
| **Documentation** | Proper justification required |

---

## Liability in Groups

| Principle | Description |
|-----------|-------------|
| **Separation** | Parent not liable for subsidiary debts |
| **Piercing veil** | Exceptional (confusion, fraud) |
| **Direct liability** | Only if parent assumed obligation |
| **Comfort letters** | May create obligations |

See [[22 - Personnalité morale]] for veil piercing.

## Special Group Issues

| Issue | Consideration |
|-------|---------------|
| **Upstream guarantees** | Corporate benefit analysis needed |
| **Cash pooling** | Intercompany lending rules |
| **Management fees** | Must be justified |
| **Asset transfers** | At fair value |
