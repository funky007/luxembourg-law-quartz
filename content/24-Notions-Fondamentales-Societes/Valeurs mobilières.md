# Valeurs mobilières

> **Type**: Notion Fondamentale
> **Source**: Steichen, *Précis de droit des sociétés*, Titre 4, Ch. 1
> **Key Legislation**: Arts. 430-1 to 430-3 L1915; Loi du 6 avril 2013

---

## Definition

**Steichen**: *Valeurs mobilières* (securities) are standardized financial instruments issued in series, conferring identical rights within each category, and capable of being traded on financial markets.

---

## Categories

| Category | Description |
|----------|-------------|
| **Titres de capital** | Equity instruments (shares) |
| **Titres de créance** | Debt instruments (bonds) |
| **Titres composés** | Hybrid instruments |
| **Titres dérivés** | Options, warrants |

---

## Equity Securities (*Titres de capital*)

| Type | Description |
|------|-------------|
| **Actions ordinaires** | Standard voting shares |
| **Actions privilégiées** | Preferred shares |
| **Actions sans droit de vote** | Non-voting shares |
| **Parts bénéficiaires** | Profit participation rights |

See [[Actions]] for details.

## Debt Securities (*Titres de créance*)

| Type | Description |
|------|-------------|

| **Obligations échangeables** | Exchangeable bonds |

## Hybrid Securities

| Type | Description |
|------|-------------|
| **Obligations convertibles** | Convert to shares |
| **Obligations avec warrants** | Bond plus subscription right |

---

## Dematerialization

**Loi du 6 avril 2013**: Luxembourg permits:

| Form | Description |
|------|-------------|
| **Registered** | In company register |
| **Bearer** | Physical certificates |
| **Dematerialized** | Book-entry only |
| **Securities account** | Held with intermediary |

---

## Issuance

**Steichen**: Issuance requirements:

| Aspect | Rule |
|--------|------|
| **Board authority** | Or delegated authority |
| **Prospectus** | If public offering |
| **Registration** | With company or settlement system |
| **Publication** | As required |

---

## Transfer

| Type | Transfer Mechanism |
|------|-------------------|
| **Registered** | Entry in register |
| **Bearer** | Physical delivery |
| **Dematerialized** | Book-entry transfer |
| **Listed** | Through settlement system |

---

## Banking & Finance Application

- Understand security type for collateral
- Transfer mechanisms affect enforcement
- Dematerialization simplifies pledges
- Listed vs. unlisted affects procedures
